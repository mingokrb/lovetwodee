# pong

## controls
### P1
`[W]` - up<br>
`[S]` - down<br>
### P2
`[Up]` - up<br>
`[Down]` - down<br>
### other
`[ESC]` - pause (hold to quit)<br>
`[Space]` - toggle P2 AI<br>
