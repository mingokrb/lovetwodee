# minesweeper
i made this from memory lol it could be entirely inaccurate

## controls
just classic minesweeper i think<br>
`[MB1]` - reveal slot (if not flagged)<br>
`[MB2]` - mark slot with flag / question mark<br>
<br>
click the little yellow face to start a new game<br>
